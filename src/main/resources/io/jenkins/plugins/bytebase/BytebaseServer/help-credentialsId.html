This dropdown selects a credential stored in Jenkins. Choose one of these formats:

  • Username with password: Username is the email of a Bytebase service account, for example ci@service.bytebase.com. Password is the Service Key issued for that service account in Bytebase. Give the Jenkins credential an ID such as bytebase-ci, then select it here.
  • Secret text (legacy compatibility): Secret is an existing Bytebase access token, without the Bearer prefix. The plugin does not renew this token.

For a service account, click Add, select Username with password, and fill in the email, secret and ID above. These are Bytebase credentials, not Jenkins login credentials.

This default may be empty only when the job supplies credentialsId. A job can also override this default with its own credential ID. To use Test connection, select a default credential here. Folder credentials must be selected by ID from a job in that folder.

Successful connection testing confirms authentication and connectivity. SQL review and rollout also require the corresponding Bytebase permissions on the target project.
